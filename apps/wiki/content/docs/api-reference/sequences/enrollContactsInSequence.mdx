Enroll contacts into a sequence. They start at the first published step, and their enrollment time anchors that step's delay. Enrolling someone twice is a silent no-op.

Explicit lists of 100 IDs or fewer are enrolled synchronously and return the outcome. Anything larger, and any `query`-mode selector, is queued and returns a job ID to poll.
